# WCT — current brand system

Source: current guidelines supplied directly by the user in this chat. These values supersede older local reference files.

| Element | Guideline |
| --- | --- |
| Primary background | Warm paper `#f4f1ea` |
| Primary brand color | Deep olive `#26351f` |
| Accent | Restrained gold `#9d7744` |
| Secondary neutral | Muted grey/olive `#68685f` |
| Text | Dark ink / near-black |
| Logo | White WCT logo on dark olive or other dark surfaces |
| Primary actions | Olive |
| Gold | Accent only |
| Gradients | Avoid |
| Shadows | Minimal and restrained |
| Borders | Thin, subtle rules |
| Corner radii | Limited; not heavily rounded |
| Pills/chips | Avoid excessive pill shapes |

OTSec applies 4px surface/button corners, 3px form controls, 2px status labels and 6px dialogs. Small circular connection indicators are retained. Gold is limited to small metadata accents, focus indicators and review callouts. Inter remains the application typeface, with Plex Mono for technical identifiers. These typography choices supplement the supplied guidelines.
