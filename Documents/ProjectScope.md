The first release will focus on demonstrating the complete secure lifecycle of the platform rather than implementing every possible industrial technology.

### In Scope

- Asset management
- User authentication
- Role-based authorization
- Device authentication
- HTTPS telemetry ingestion
- MQTT telemetry ingestion
- PostgreSQL persistence
- Python device simulation
- Security events
- Audit logging
- Basic security alerting
- Threat modeling
- Security requirements
- Automated testing
- Negative security testing
- SAST
- Software composition analysis
- SBOM generation
- Container scanning
- CI/CD security controls
- Vulnerability remediation

### Future Extensions

The following technologies may be added after completion of the initial release:

- Physical embedded devices
- PLC integration
- Modbus TCP
- Modbus RTU
- CAN
- OPC UA
- OT gateway architecture
- Mutual TLS
- Device certificates
- Advanced PKI
- Industrial network zoning
- Advanced behavioral detection
- TimescaleDB
- Additional renewable-energy and utility devices

Industrial protocols are expected to eventually connect through an OT gateway rather than being exposed directly to the application backend.
